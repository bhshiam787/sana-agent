# LinkedIn playbook (read-only)

- Read only: search, scroll, open posts and profiles. Never like, comment, message, follow, connect,
  apply, or change any setting. Never click "Easy Apply".
- Be slow: wait a few seconds between pages; at most the page budget given in the task.
- Use content search (Posts) with queries like "PhD position <topic>", "funded PhD <topic>",
  "hiring PhD student <topic>", limited to the past month when the filter is available.
- For each relevant post record: author name and role, institution, post URL, topic, funding
  details, deadline, and the application link if present.
- If LinkedIn shows a login wall, CAPTCHA, or "unusual activity" warning: stop immediately and
  report it. Do not try to get around it.
